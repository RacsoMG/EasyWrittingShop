# EasyWorkShop

Professional research and academic writing services for college, undergraduate, and postgraduate students.

## Overview

EasyWorkShop provides high-quality analytical and investigative research support across various fields, including economics, medicine, and psychology. Our team of experts is dedicated to supporting your academic success through rigorous methodology and comprehensive insights.

## Key Services

- **Research Papers**: In-depth analytical papers across all academic fields.
- **Thesis & Dissertation Support**: Comprehensive guidance from proposal to final submission.
- **Data Analysis**: Statistical interpretation using advanced tools (SPSS, R, Python).
- **Academic Editing**: Professional proofreading to meet the highest standards.

## Technology Stack

- **Frontend**: React, Vite, Tailwind CSS
- **UI Components**: Radix UI, Lucide Icons, Framer Motion
- **State Management**: React Query (TanStack Query)
- **Styling**: Tailwind CSS with custom animations

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4.  Open your browser and navigate to:
 👉 http://localhost:5173
## Project Structure

- `src/components`: Reusable UI components.
- `src/pages`: Application pages (Home, Services, Projects, Contact, Admin).
- `src/lib/local-data.js`: Standalone data persistence layer using LocalStorage.
- `entities/`: Data schemas and initial seed data (CSV/SQL).
